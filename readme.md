# AI Fundamentals in the Workplace – Capstone Project Based on Sadaia Academy quiz

This project demonstrates how I used ChatGPT to convert unorganised
notes into a clear onboarding checklist for the Taypos restaurant
management platform.

The project includes:

- A real recurring text-based task
- A structured R.A.C.E. prompt
- An iterative follow-up prompt
- Data masking and privacy protection
- Output verification
- An estimate of the time saved
